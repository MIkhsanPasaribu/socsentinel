## 🧩 Challenge Tracks

### 🤖 Track 1: AI Agents & Agentic Workflows *(Best for Beginners)*

- **Objective:** Move beyond simple RAG to build sophisticated AI agentic systems and workloads.
- **What to Build:** Intelligent AI systems that automate workflows, coordinate agents, or assist users in complex tasks.
- **Tech Stack:** LangChain, CrewAI, AutoGen + open-source models (Llama, DeepSeek, Mistral, Qwen)
- **Compute:** $100 in AMD Developer Cloud credits

---

### ⚡ Track 2: Fine-Tuning on AMD GPUs *(Advanced / GPU-Intensive)*

- **Objective:** Leverage direct GPU access to fine-tune open-source models for high-impact domain specialization.
- **What to Build:** Domain-specific LLMs (Healthcare, Finance, Legal, or Code) fine-tuned for accuracy and efficiency on ROCm.
- **Tech Stack:** ROCm, PyTorch, Hugging Face Optimum-AMD, vLLM
- **Compute:** AMD Instinct MI300X instances via AMD Developer Cloud

---

### 🎨 Track 3: Vision & Multimodal AI

- **Objective:** Build applications that process and understand multiple data types (Images, Video, Audio) using AMD GPU's massive memory bandwidth.
- **What to Build:** High-throughput industrial inspection, medical imaging analysis, or multimodal conversational assistants.
- **Tech Stack:** Llama 3.2 Vision, Qwen-VL — optimized for ROCm™
- **Compute:** AMD Instinct MI300X instances via AMD Developer Cloud

---

### 🚢 Extra Challenge: Ship It + Build in Public

- **Objective:** Document your building journey, share insights, and provide feedback on the AMD developer experience.

**Requirements:**
1. Share at least **2 technical updates** on social media (tag `@lablab` on X / `lablab.ai` on LinkedIn, and tag `@AIatAMD` on X / `AMD Developer` on LinkedIn)
2. Provide **meaningful feedback** about building with ROCm, AMD Developer Cloud, or its APIs
3. **Open-source** your project or publish a technical walkthrough of how you built it

> ✅ This challenge can be completed alongside any hackathon track.

## 🛠️ Technology & Access

### AMD Developer Cloud
- On-demand access to AMD Instinct GPUs via the cloud
- No hardware needed — spin up powerful GPU environments in minutes
- **Access:** $100 credits for AMD AI Developer Program members + pay-as-you-go pricing

### ROCm (Radeon Open Compute)
- AMD's open-source GPU computing platform (AMD's equivalent of NVIDIA's CUDA)
- Supports PyTorch, TensorFlow, and porting CUDA-based workloads to AMD hardware
